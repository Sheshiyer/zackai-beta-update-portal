# WhatsApp Automation Templates

These templates power ZackAI's WhatsApp automation via [Interakt](https://app.interakt.ai). Each is written in the Playful Guardian brand voice — warm, reassuring, and parent-trustworthy. All template IDs use snake_case with a `_zackai` suffix for namespace clarity.

**Variable format:** `{{variable_name}}` — standard WhatsApp/Interakt placeholder syntax.

---
